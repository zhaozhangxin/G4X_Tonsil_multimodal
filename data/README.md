# Data Setup

This directory holds all raw and processed data for the G4X tonsil preprocessing
pipeline. Raw data files are large and are excluded from the Git repository (see
`.gitignore`). Follow the instructions below to populate this directory before
running any pipeline scripts.

---

## 1. Overview of Required Data

The pipeline was developed and validated on the **Singular Genomics G4X human
tonsil (Rep 1)** dataset, which contains:

| Modality | Description |
|---|---|
| H&E image | Whole-tissue hematoxylin and eosin image (JP2 format) |
| RNA transcripts | 22,148,004 transcripts across 348 genes with pixel coordinates |
| Protein OME-TIFF | 16-channel multiplex protein image (nuclear + 15 markers) |

---

## 2. Directory Structure

Create the following subdirectories under `data/` before downloading:

```
data/
├── raw/
│   ├── h_and_e/          # H&E whole-tissue image
│   ├── rna/              # RNA transcript table
│   └── ometiff/          # Multi-channel protein OME-TIFF
└── processed/            # Generated by pipeline scripts (do not create manually)
    └── 260316_g4xtonsil_cell/   # Created by 02_segmentation.py
```

Run these commands to create the raw subdirectories:

```bash
mkdir -p data/raw/h_and_e
mkdir -p data/raw/rna
mkdir -p data/raw/ometiff
```

---

## 3. Where to Download

The G4X tonsil dataset is available from **Singular Genomics**:

- Product page / data portal: https://singulargenomics.com
- If the dataset has been deposited in a public repository, check the manuscript
  or supplementary materials for the accession number (e.g., GEO, Zenodo, or
  Figshare).

Contact Singular Genomics directly if you cannot locate the public download link.

---

## 4. Required Raw Files

Place each file in the indicated path relative to the repository root.

| File path | Size | Description |
|---|---|---|
| `data/raw/h_and_e/h_and_e.jp2` | ~large | H&E whole-tissue image in JPEG 2000 format |
| `data/raw/rna/transcript_table.csv.gz` | ~292 MB | Transcript table with `gene_name`, `x_pixel_coordinate`, and `y_pixel_coordinate` columns |
| `data/raw/ometiff/G04.ome.tiff` | ~4.5 GB | Multi-channel protein OME-TIFF (16 channels: nuclear + 15 markers including CD20, PanCK, CD45RA, CD3, etc.) |

---

## 5. Processed Files (Pipeline-Generated)

The following files are **not** downloaded — they are produced by running the
pipeline scripts in order:

| File path | Produced by | Description |
|---|---|---|
| `data/processed/260316_g4xtonsil_cell/segmentation_mask.tiff` | `02_segmentation.py` | Integer label mask (230,446 cells) |
| `data/processed/260316_g4xtonsil_cell/dataScaleSize.csv` | `02_segmentation.py` | Per-cell protein marker intensities normalized by cell area |
| `data/processed/260316_g4xtonsil_cell/segmentation.geojson` | `03_convert_to_geojson.py` | GeoJSON polygons for QuPath visualization |

---

## 6. Notes on Large Files and Git LFS

Raw data files are large (hundreds of MB to several GB) and are excluded from
version control via `.gitignore`. If you wish to track processed outputs with
Git, consider using [Git Large File Storage (Git LFS)](https://git-lfs.com/):

```bash
git lfs install
git lfs track "*.tiff"
git lfs track "*.h5ad"
git lfs track "*.h5mu"
git lfs track "*.geojson"
git add .gitattributes
```

For most use cases it is simpler to keep large data files outside version
control and document their provenance here.
